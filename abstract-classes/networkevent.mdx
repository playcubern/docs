---
title: "NetworkEvent"
description: "NetworkEvent is the abstract class for events that communicate between the server and clients"
icon: "network-wired"
---

<Note iconType="regular">
  NetworkEvent inherits Instance.
</Note>

<Warning iconType="regular">
  This is an abstract class.
</Warning>

The base class for instances that send messages between the server and clients, such as
[RemoteEvent](/classes/remoteevent) and
[UnreliableRemoteEvent](/classes/unreliableremoteevent). It has no additional
properties, methods or events of its own.
