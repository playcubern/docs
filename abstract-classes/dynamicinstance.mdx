  DynamicInstance inherits Instance.

<Warning iconType="regular">

</Warning>

<Warning iconType="regular">
  This is an abstract class.
</Warning>

## Properties
### `Position: Vector3`
The position of the instance in the world.

### `LocalPosition: Vector3`
The position of the instance relative to its parent. If the parent is not a
DynamicInstance, this is the same as `Position`. Example:
```lua
-- Place the part 5 studs above its parent, wherever the parent is
workspace.Model.Part.LocalPosition = Vector3.new(0, 5, 0)
```

### `Scale: Vector3`
The scale of the instance.

### `Rotation: Vector3`
The rotation of the instance in radians.

### `RotationDegrees: Vector3`
The rotation of the instance in degrees.

### `LocalRotation: Vector3`
The rotation of the instance in radians, relative to its parent. If the parent
is not a DynamicInstance, this is the same as `Rotation`. Example:
```lua
-- Turn the part 90 degrees around its parent's Y axis
workspace.Model.Part.LocalRotation = Vector3.new(0, math.rad(90), 0)
```

### `Anchored: boolean`
Whether the instance is anchored. Anchored instances are not affected by physics.

### `CanCollide: boolean`
Whether the instance can collide with other instances.

### `CanTouch: boolean`
Whether the instance fires `Touched` and `TouchEnded` events when other instances touch it.

---

## Events
### `Touched: Event<DynamicInstance>`
Fired whenever another DynamicInstance begins touching this instance. Passes the instance that started the touch. Example:
```lua
workspace.Part.Touched:Connect(function(other: DynamicInstance)
    print(other.Name .. " touched the part")
end)
```

### `TouchEnded: Event<DynamicInstance>`
Fired whenever another DynamicInstance stops touching this instance. Passes the instance that stopped touching.
