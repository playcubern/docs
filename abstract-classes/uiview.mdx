<Note iconType="regular">
  UiView inherits UiInstance.
</Note>

<Warning iconType="regular">
  This is an abstract class.
</Warning>

UiView adds background, corner radius and border styling on top of
[UiInstance](/abstract-classes/uiinstance). UI classes such as
[UiPanel](/classes/uipanel), [UiLabel](/classes/uilabel),
[UiButton](/abstract-classes/uibutton) and
[UiTextInput](/classes/uitextinput)
inherit from it.

## Properties
### `BackgroundColor: Color3`
The background color of the view.

### `BackgroundTransparency: number`
How see-through the background is, from `0` (fully opaque) to `1` (fully
invisible). Values outside that range are clamped. Unlike
[Transparency](/abstract-classes/uiinstance#transparency-number), it only
affects the background, not the border, text or children. Example:
```lua
script.Parent.BackgroundTransparency = 0.5
```

### `BackgroundTransparent: boolean`
<Warning iconType="regular">
  This property is deprecated. Use `BackgroundTransparency` instead.
</Warning>
Whether the background is fully transparent. Setting it to `true` is the same
as setting `BackgroundTransparency` to `1`, and `false` is the same as `0`.

### `CornerRadiusTopLeft: number`
The corner radius of the top-left corner.

### `CornerRadiusTopRight: number`
The corner radius of the top-right corner.

### `CornerRadiusBottomLeft: number`
The corner radius of the bottom-left corner.

### `CornerRadiusBottomRight: number`
The corner radius of the bottom-right corner.

### `BorderColor: Color3`
The color of the border.

### `BorderWidthTop: number`
The width of the top border.

### `BorderWidthBottom: number`
The width of the bottom border.

### `BorderWidthLeft: number`
The width of the left border.

### `BorderWidthRight: number`
The width of the right border.
