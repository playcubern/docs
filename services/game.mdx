<Note iconType="regular">
  Game inherits ServiceProvider.
</Note>

The `game` global is the root of the data model. Every service is a child of it.

## Properties
### `Workspace: Workspace`
A reference to the [Workspace](/services/workspace) service.

### `Players: Players`
A reference to the [Players](/services/players) service.

### `IsLoaded: boolean`
Whether the game has finished loading.

### `EditorCameraPosition: Vector3`
The position of the editor camera, saved with the game so the editor reopens at
the same spot. It is only used by the editor and has no effect in a running game.

### `EditorCameraRotation: Vector3`
The rotation of the editor camera, saved with the game so the editor reopens at
the same angle. It is only used by the editor and has no effect in a running game.

---

## Methods
### `GetService(serviceName: string): Instance`
Returns the service with the given name. Example:
```lua
local players = game:GetService("Players")
```
