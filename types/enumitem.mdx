An `EnumItem` is a single value of an enum, such as `Enum.PartShape.Sphere`.
Every enum value inherits from `EnumItem`.

## Properties
### `Name: string`
The name of the enum item, for example `"Sphere"`.

### `Value: number`
The underlying numeric value of the enum item.
