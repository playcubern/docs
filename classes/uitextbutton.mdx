<Note iconType="regular">
  UiTextButton inherits UiButton.
</Note>

A clickable button that displays text. In addition to everything inherited
from [UiButton](/abstract-classes/uibutton), it has the following members.

## Properties
### `Text: string`
The text displayed on the button.

### `TextSize: number`
The size of the text in pixels.

### `TextColor: Color3`
The color of the text.

### `FontWeight: FontWeight`
The weight of the font. See the [FontWeight](/enums/fontweight) enum for the available values.

### `HorizontalAlignment: HorizontalAlignment`
The horizontal alignment of the text. See the [HorizontalAlignment](/enums/horizontalalignment) enum for the available values.
