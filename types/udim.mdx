## Properties
### `Scale: number`
The scale of the UDim.

### `Offset: number`
The offset of the UDim.

---

## Operators

### Addition: `+`

Adds two `UDim` values together.
Each component (`Scale`, `Offset`) is added separately.
Returns the resulting `UDim`.

**Do remember:** The `Scale` component is **clamped** from 0 to 1.0.

**Example:**

```lua
local a = -- a UDim with Scale 0.5, Offset 10
local b = -- a UDim with Scale 0.25, Offset -5
local c = a + b -- UDim(0.75, 5)
```

---

### Subtraction: `-`

Subtracts the second `UDim` from the first.
Each component (`Scale`, `Offset`) is subtracted separately.
Returns the resulting `UDim`.

**Do remember:** The `Scale` component is **clamped** from 0 to 1.0.

---

### Unary Minus: `-`

Negates a `UDim`, returning a new value where each component (`Scale`, `Offset`) is multiplied by `-1`.
This effectively inverts the direction or sign of the `UDim` without modifying the original value.

**Do remember:** The `Scale` component is **clamped** from 0 to 1.0.
