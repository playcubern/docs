---

## Operators
### Addition: `+`
Adds two UDim2 values together.
Each component (X.Scale, X.Offset, Y.Scale, Y.Offset) is added separately.
Then returns the final sum.

Example:
```lua
local a = UDim2.new(0.5, 10, 0.5, 20)
local b = UDim2.new(0.25, -10, 0, 5)
local c = a + b -- UDim2(0.75, 0, 0.5, 25)
```

---

### Subtraction: `-`
Subtracts each component of the second UDim2 from the first and returns the resulting UDim2.

Do remember the Scale component is **clamped** from 0 to 1.0.

Example:
```lua
local a = UDim2.new(0.5, 10, 0.5, 20)
local b = UDim2.new(0.25, -10, 0, 5)
local c = a - b -- UDim2.new(0.25, 20, 0.5, 15)
```

---

### Unary Minus: `-`
Negates the UDim2, returning a new value where each component (X.Scale, X.Offset, Y.Scale, Y.Offset) is multiplied by -1.
This effectively inverts the direction or sign of the UDim2 without modifying the original value.

Do remember the Scale component is **clamped** from 0 to 1.0.

Example:
```lua
local a = UDim2.new(0.5, 10, 0.5, 20)
local b = -a -- b becomes: UDim2(0.5, -10, 0.5, -20)
```
