A `DataStore` is a persistent key-value store used to save and load data that
survives between sessions. DataStores are obtained from the
[DataStoreService](/services/datastoreservice) with `GetDataStore`.

## Methods
### `GetAsync(key: string): any`
Returns the value stored at the given key, or `nil` if no value has been set. The return value is cached for 4 seconds.
Example:
```lua
local store = game:GetService("DataStoreService"):GetDataStore("PlayerData")

local coins = store:GetAsync("coins")
print(coins)
```

### `SetAsync(key: string, value: any): boolean`
Stores `value` at the given key. Returns `true` if the value was saved
successfully. Example:
```lua
local store = game:GetService("DataStoreService"):GetDataStore("PlayerData")

local success = store:SetAsync("coins", 100)
if success then
    print("Saved!")
end
```

### `RemoveAsync(key: string): boolean`
Removes the value stored at the given key. Returns `true` if the value was
removed successfully. Example:
```lua
local store = game:GetService("DataStoreService"):GetDataStore("PlayerData")

local success = store:RemoveAsync("coins")
if success then
    print("Removed!")
end
```

### `Disconnect(): nil`
Disconnects the DataStore, releasing it so it is no longer kept in memory. Do not
call any further methods on the DataStore after disconnecting it. Example:
```lua
local store = game:GetService("DataStoreService"):GetDataStore("PlayerData")

store:Disconnect()
```
