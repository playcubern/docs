  This is an abstract class.
</Warning>

[Game](/services/game) inherits from ServiceProvider, which is how services are
retrieved.

## Methods
### `GetService(className: ServiceType): Instance`
Returns the service with the given name. `ServiceType` is one of:
`"Workspace"`, `"ReplicatedStorage"`, `"ServerStorage"`, `"Scripts"`,
`"LocalScripts"`, `"Players"`, `"PlayerGui"`, `"Environment"` or `"RunService"`.

Example:
```lua
local players = game:GetService("Players")
```
