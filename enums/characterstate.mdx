The `CharacterState` enum defines the current state of a
[Character](/classes/character). Each value is an [EnumItem](/types/enumitem)
accessed through `Enum.CharacterState`.

## Values
### `Enum.CharacterState.Idle`
The character is standing still.

### `Enum.CharacterState.Running`
The character is moving.

### `Enum.CharacterState.Jumping`
The character is in the air from jumping.

### `Enum.CharacterState.Landed`
The character has just landed after being airborne.

### `Enum.CharacterState.Dead`
The character has died.

---

## Methods
### `GetEnumItems(): { CharacterState }`
Returns a table of every `CharacterState` value. Example:
```lua
for _, state in Enum.CharacterState:GetEnumItems() do
    print(state.Name)
end
```
