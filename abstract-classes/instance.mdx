<Note iconType="regular">
  Instance is an abstract class and every datamodel inherits from this.
</Note>

<Warning iconType="regular">
  This class cannot be created from `Instance.new`
</Warning>

## Properties
### `Name: string`
The name of the instance inside the game. Example:
```lua
print(workspace.Part.Name) -- outputs the name which would be "Part" here.
```

### `ClassName: string`
The classname of the instance.

### `Parent: Instance`
The parent of the instance inside the game.

---

## Constructors
### `Instance.new(className: string, parent: Instance?): Instance`
Creates a new instance of the given class. Optionally parents it to `parent`.
Example:
```lua
local part = Instance.new("Part")
part.Parent = workspace
```

---

## Methods
### `Clone(): Instance`
Clones the instance and returns it. Example:
```lua
local part = workspace.Part
local newPart = part:Clone()
newPart.Name = "ClonedPart"
newPart.Parent = workspace
```

### `ClearAllChildren(): nil`
Clears all of the instance's children.

### `FindFirstChild(name: string): Instance?`
Tries to find the child with the given name. Example:
```lua
local part: Instance? = workspace:FindFirstChild("Part")
if not part then
    print("Part was not found")
else
    print("Part exists!")
end
```

### `FindFirstChild(name: string, recursive: boolean): Instance?`
Tries to find the child with the given name. When `recursive` is true the search continues through descendants.

### `FindFirstChildOfClass(className: string): Instance?`
Tries to find the first child whose `ClassName` matches the given string. Example:
```lua
local script = workspace.Part:FindFirstChildOfClass("Script")
```

### `FindFirstAncestor(name: string): Instance?`
Works upward from the parent to find an ancestor with the given name.

### `FindFirstAncestorOfClass(className: string): Instance?`
Works upward to find the first ancestor whose `ClassName` matches the given string.

### `FindFirstAncestorWhichIsA(className: string): Instance?`
Works upward to find the first ancestor that inherits from the given class.

### `Destroy(): nil`
Destroys the instance from the game. Do remember to NOT make use of any methods or properties after
destroying an instance! Example:
```lua
local part = workspace.Part
part:Destroy()
```

### `IsA(className: string): boolean`
Returns true if the instance is of the given type. Example:
```lua
local part = workspace.Part
print(part:IsA("Part")) -- will print true
```

### `IsAncestorOf(descendant: Instance): boolean`
Returns true if the instance is an ancestor of the given descendant. Example:
```lua
print(workspace:IsAncestorOf(workspace.Part)) -- will be true
```

### `IsDescendantOf(ancestor: Instance): boolean`
Returns true if the instance is a descendant of the given ancestor. Example:
```lua
print(workspace.Part:IsDescendantOf(workspace)) -- will be true
```

### `GetAttribute(name: string): any`
Returns the value of the attribute with the given name, or nil if it does not exist.

### `SetAttribute(name: string, value: any): nil`
Sets the value of the attribute with the given name.

### `GetAttributes(): { [string]: any }`
Returns a table of all attributes on the instance keyed by name.

### `AddTag(tag: string): boolean`
Adds the tag to the instance. Tags added from the server-side will replicate to all of the connected clients.
Example:
```lua
workspace.Part:AddTag("MyTag")
```

### `RemoveTag(tag: string): nil`
Removes the tag from the instance, if found. Tags removed from the server-side will replicate to all of the connected clients.
Example:
```lua
workspace.Part:RemoveTag("MyTag")
```

### `WaitForChild(name: string): Instance`
Waits for the child with the given name. The script will yield until the instance is found. Example:
```lua
local exists = workspace:WaitForChild("Exists") -- yields until found, then returns
```

### `WaitForChild(name: string, timeout: number): Instance?`
Waits for the child with the given name, yielding until it is found or the given timeout occurs.

### `GetChildren(): { Instance }`
Returns a table containing all of the children instances of this instance.

### `GetDescendants(): { Instance }`
Returns a table containing all of the descendants of this instance.

### `GetFullName(): string`
Returns the full name of the instance. Example: `Workspace.Part`

### `GetTags(): { any }`
Returns all the tags associated with the instance.

### `HasTag(tag: string): boolean`
Returns true if the instance has the given tag. Example:
```lua
workspace.Part:HasTag("MyTag")
```

## Events
### `ChildAdded: Event<Instance>`
Fired whenever a new child is added to the instance. Example:
```lua
workspace.Part.ChildAdded:Connect(function(childAdded: Instance)
    print("Child added named: " .. childAdded.Name)
end)
```

### `ChildRemoved: Event<Instance>`
Fired whenever a child is no longer a child of the instance. Example:
```lua
workspace.Part.ChildRemoved:Connect(function(childRemoved: Instance)
    print("Child removed named: " .. childRemoved.Name)
end)
```

### `ChildrenCleared: Event`
Fired whenever all children of the instance are cleared.

### `AncestryChanged: Event<Instance, Instance?>`
Fired whenever the instance's ancestry changes. Passes the affected instance and its new parent.

### `AttributeChanged: Event<string>`
Fired whenever an attribute of the instance changes. Passes the name of the changed attribute.

### `PropertyChanged: Event<string, any>`
Fired whenever a property of the instance changes. Example:
```lua
workspace.Part.PropertyChanged:Connect(function(propertyName: string, newValue: any)
    print("Property changed: " .. propertyName)
end)
```

### `Destroying: Event`
Fired whenever `Destroy()` is called on this instance.
