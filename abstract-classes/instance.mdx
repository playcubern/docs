<Note iconType="regular">
  Instance is an abstract class and every datamodel inherits from this.
</Note>

<Warning iconType="regular">
  This class cannot be created from `Instance.New`
</Warning>

## Properties
### `Name: string`
The name of the instance inside the game. Example:
```lua
print(workspace.Part.Name) -- outputs the name which would be "Part" here.
```

### `ClassName: string`
The classname.

### `Parent: Instance`
The parent of the instance inside the game.

### `Archivable: boolean`
If the instance is serializable or not. Default: true. 

---

## Methods 
### `static` `New(classType: string): Instance`
Example:
```lua
local part = Instance.New("Part")
part.Parent = workspace
```

### `Clone() : ()`
Clones the instance and returns it. 
Example:
```lua
local part = workspace.Part
local newPart = part:Clone()
newPart.Name = "ClonedPart"
newPart.Parent = workspace
```

### `GetChildren() : {Instance}`
Returns a table containing all of the children instances of this instance.

### `GetChildAt(index: number) : Instance?`
Returns the child at the index number given.

### `GetDescendants() : {Instance}`
Returns a table containing all of the descendants.

### `GetParent() : Instance?`
Returns the parent of the instance. Nil if none.

### `GetFullName(): string`
Returns the full name of the instance. Example: `Workspace.Part`

### `Destroy() : ()`
Destroys the instance from game. Do remember to NOT make use of any methods or properties after
destroying an instance! Example:
```lua
local part = workspace.Part
part:Destroy()
```

### `IsA(className: string): boolean`
Returns a boolean if the instance is of type given. For example:
```lua
local part = workspace.Part
print(part:IsA("Part")) -- will print true
```

### `FindFirstChild(childName: string, recursive: boolean = false): Instance?`
Tries to find the child with the name given in method. Example:
```lua
local part: Instance? = workspace:FindFirstChild("Part")
if not part then 
    print("Part was not found")
else 
    print("Part exists!")
end
```

### `FindFirstChildOfClass(className: string): Instance?`
Returns the first child whose `ClassName` matches the given string.

### `FindFirstAncestor(ancestorName: string): Instance?`
Works upward from the parent to find an ancestor with the specific name.

### `FindFirstAncestorOfClass(className: string): Instance?`
Works upward to find the first ancestor that inherits from a specific class.


### `ClearAllChildren(): ()`
Clears all of the Instance's children.

### `WaitForChild(instanceName: string): Instance`
Waits for the child with the given name. The script will yield till the instance is not found!
If no instance is found and timeout occurs, a warning will be produced. 
Example:
```lua
local doesntExist = workspace:WaitForChild("I dont exist") -- this will generate a warning 

local exists = workspace:WaitForChild("Exists") -- it will wait till not found and once found it will return
```

### `WaitForChild(instanceName: string, timeout: number): Instance?`
Waits for the child with the given name. The script will yield till the instance is not found or if the given timeout occurs.

### `IsAncestorOf(instance: Instance): boolean`
Returns true if the instance is an ancestor of the given descendant.

### `IsDescendantOf(ancestor: Instance): boolean`
Example:
```lua
print(workspace.Part:IsDescendantOf(workspace)) -- will be true
```

### `AddTag(tagName: string): ()`
Adds the tag onto the instance. Tags added from the server-side will replicate to all of the connected clients.
Example:
```lua
workspace.Part:AddTag("MyTag")
```

### `HasTag(tagName: string): boolean`
Returns true if the given instance has the given tag. 
Example:
```lua
workspace.Part:HasTag("MyTag")
```

### `GetTags(): { any }`
Returns all the tags associated with the instance.


### `RemoveTag(tagName: string): ()`
Removes the tag from the instance, if found. Tags removed from the server-side will replicate to all of the connected clients.
Example:
```lua
workspace.Part:RemoveTag("MyTag")
```
Note: It will not error or generate any warnings.

## Events
### `ChildAdded: Instance`
The event is fired whenever a new child is added to the instance. Example:
```lua
workspace.Part.ChildAdded:Connect(function(childAdded: Instance)
    print("Child added named: " .. childAdded.Name)
end)

local newPart: Part = Instance.New("Part")
newPart.Name = "newPart"
newPart.Parent = workspace.Part
```
This will print:
```
Child added named: newPart
```


### `ChildRemoved: Instance`
The event is fired whenever a child is no longer a child to the instance. Example:
```lua
workspace.Part.ChildRemoved:Connect(function(childRemoved: Instance)
    print("Child removed named: " .. childRemoved.Name)
end)

workspace.Part.newPart.Parent = nil
```
This will print:
```
Child removed named: newPart
```

### `Destroying: ()`
The event is fired whenever `Destroy()` is called of this instance.

### `AncestryChanged: ()`
The event is fired whenever a child is added or removed.

### `PropertyChanged: string, any`
The event is fired whenever the property of the instance changes. Example:
```lua
workspace.Part.PropertyChanged:Connect(function(propertyName: string, newValue: any)
    print("Property changed called: " .. propertyName .. " with value " .. newValue)
end)

Name = "NewName"
```
This will print:
```
Property changed called: Name with value NewName
```

### `TagAdded: string`
The event is fired whener a tag is added to this instance. Example:
```lua
workspace.Part.TagAdded:Connect(function(tag: string)
    print("Tag added: " .. tag)
end)
```

### `TagRemoved: string`
The event is fired whener a tag is removed from this instance. Example:
```lua
workspace.Part.TagRemoved:Connect(function(tag: string)
    print("Tag removed: " .. tag)
end)
```
