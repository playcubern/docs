<Note iconType="regular">
  UiImageLabel inherits UiInstance.
</Note>

Displays an image inside the UI. In addition to everything inherited from
[UiInstance](/abstract-classes/uiinstance), it has the following members.

## Properties
### `ImageId: number`
The id of the image to display. Setting it loads the image and shows it once it
is ready. Set it to `0` to show the placeholder image instead. Example:
```lua
script.Parent.ImageId = 1234
```
