<Note iconType="regular">
  BaseScript inherits Instance.
</Note>

<Warning iconType="regular">
  This class cannot be created from `Instance.new`
</Warning>

<Warning iconType="regular">
  This is an abstract class.
</Warning>

## Properties
### `Source: string`
The source of the script. This is readonly for other scripts.

### `Disabled: boolean`
Whether the script is disabled. A disabled script does not run.
