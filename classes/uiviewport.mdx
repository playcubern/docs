<Note iconType="regular">
  UiViewport inherits UiInstance.
</Note>

A UI element that displays a view of the 3D world. In addition to everything
inherited from [UiInstance](/abstract-classes/uiinstance), it has the following
members.

## Properties
### `Transparent: boolean`
Whether the viewport's background is transparent. Example:
```lua
script.Parent.Transparent = true
```
