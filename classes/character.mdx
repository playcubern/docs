<Note iconType="regular">
  Character inherits DynamicInstance.
</Note>

Represents a [Player](/classes/player)'s or [Npc](/classes/npc)'s avatar in
the 3D world. It controls the appearance of the avatar, including which body
parts and accessories are worn, and how it moves. Access it through a player's
[`Character`](/classes/player) property or an Npc's `Character` property.

Each body part is a [BodyPart](/classes/bodypart) child of the character, named
`Head`, `Torso`, `LeftArm`, `RightArm`, `LeftLeg` and `RightLeg`. Change a body
part's color through its `Color` property. In addition to everything inherited from
[DynamicInstance](/abstract-classes/dynamicinstance), it has the following members.

## Properties
### `Health: number`
The current health of the character. When it reaches `0`, the character dies.
Example:
```lua
game.Players.LocalPlayer.Character.Health = 50
```

### `MaxHealth: number`
The maximum health the character can have. Example:
```lua
game.Players.LocalPlayer.Character.MaxHealth = 200
```

### `WalkSpeed: number`
How fast the character moves, in studs per second. Example:
```lua
game.Players.LocalPlayer.Character.WalkSpeed = 32
```

### `JumpPower: number`
How high the character can jump. Example:
```lua
game.Players.LocalPlayer.Character.JumpPower = 75
```

### `State: CharacterState`
The character's current state. See the [CharacterState](/enums/characterstate) enum for the available values.

### `MoveDirection: Vector3`
The direction the character is currently walking in, whether from player input
or from `Move` and `MoveTo`. It is `Vector3.new(0, 0, 0)` while standing still.
This property is read-only.

### `AnimationState: number`
The animation the character is currently playing: `0` for idle, `1` for walking
and `2` for jumping. It is used internally to replicate animations and is
hidden from the properties panel.

### `HeadId: number`
The identifier of the head worn by the character.

### `TorsoId: number`
The identifier of the torso worn by the character.

### `FaceId: number`
The identifier of the face worn by the character.

### `ShirtId: number`
The identifier of the shirt worn by the character.

### `PantsId: number`
The identifier of the pants worn by the character.

### `Hat1: number`
The identifier of the character's first hat accessory.

### `Hat2: number`
The identifier of the character's second hat accessory.

### `Hat3: number`
The identifier of the character's third hat accessory.

### `Hat4: number`
The identifier of the character's fourth hat accessory.

## Methods
<Note iconType="regular">
  `Move`, `MoveTo` and `Jump` only take effect where the character is simulated:
  on the client for the local player's character, and on the server for an
  [Npc](/classes/npc)'s character (or on the client for an Npc created there).
  They are ignored while the character is dead or anchored.
</Note>

### `Move(direction: Vector3): ()`
Makes the character walk in the given direction until told otherwise. Only the
horizontal (`X` and `Z`) part of the direction is used, and directions longer
than `1` are normalized. Pass `Vector3.new(0, 0, 0)` to stop. Cancels any
`MoveTo` in progress. Example:
```lua
local character = workspace.Npc.Character

character:Move(Vector3.new(1, 0, 0))
task.wait(2)
character:Move(Vector3.new(0, 0, 0))
```

### `MoveTo(position: Vector3): ()`
Makes the character walk towards the given position. `MoveToFinished` fires
with `true` once it gets within half a stud of it horizontally, or with `false`
if it doesn't arrive within 8 seconds, is interrupted by another `Move` or
`MoveTo`, or can't be moved. Example:
```lua
local character = workspace.Npc.Character

character.MoveToFinished:Connect(function(reached: boolean)
    print(reached and "Arrived" or "Gave up")
end)

character:MoveTo(Vector3.new(20, 0, 20))
```

### `Jump(): ()`
Makes the character jump.

## Events
### `HealthChanged: Event`
Fired whenever the character's `Health` changes. Example:
```lua
game.Players.LocalPlayer.Character.HealthChanged:Connect(function(health)
    print("Health is now", health)
end)
```

### `MaximumHealthChanged: Event`
Fired whenever the character's `MaxHealth` changes.

### `AppearanceChanged: Event`
Fired whenever any of the character's appearance properties change, such as its
worn body parts, accessories or body part colors.

### `Died: Event`
Fired when the character's `Health` reaches `0` and it dies. Example:
```lua
game.Players.LocalPlayer.Character.Died:Connect(function()
    print("The character died")
end)
```

### `MoveToFinished: Event<boolean>`
Fired when a `MoveTo` ends. Passes `true` if the character reached the target,
or `false` if it timed out or was interrupted.

### `StateChanged: Event<CharacterState>`
Fired whenever the character's `State` changes. Passes the new
[CharacterState](/enums/characterstate). Example:
```lua
game.Players.LocalPlayer.Character.StateChanged:Connect(function(state: CharacterState)
    print("State is now", state.Name)
end)
```
