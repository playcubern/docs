  PointLight inherits DynamicInstance.
</Note>

## Properties
### `ShadowEnabled: boolean`
Whether the light casts shadows. Example:
```lua
script.Parent.ShadowEnabled = true
```

### `Brightness: number`
How bright the light is. Example:
```lua
script.Parent.Brightness = 2
```

### `Range: number`
How far the light reaches, in studs. Example:
```lua
script.Parent.Range = 16
```

### `Angle: number`
The angle of the light's cone, in degrees. Example:
```lua
script.Parent.Angle = 45
```
