<Note iconType="regular">
  UiInstance inherits Instance.
</Note>

<Warning iconType="regular">
  This class cannot be created from `Instance.new`
</Warning>

<Warning iconType="regular">
  This is an abstract class.
</Warning>

## Properties
### `Position: UDim2`
The position of the UI instance relative to its parent.

### `Size: UDim2`
The size of the UI instance relative to its parent.

### `AnchorPoint: Vector2`
The anchor point of the UI instance.

### `AbsolutePosition: Vector2`
<Note iconType="regular">
  This property is read-only.
</Note>
The position of the UI instance on the screen, in pixels.

### `Rotation: number`
The rotation of the UI instance in degrees.

### `ZIndex: number`
The ZIndex of the UI instance. Used for layering properly.

### `Active: boolean`
Whether the UI instance should receive input.

### `Visible: boolean`
Whether the UI instance should be visible.

### `Transparency: number`
How see-through the UI instance is, from `0` (fully opaque) to `1` (fully
invisible). Values outside that range are clamped. It only affects this
instance, not its children. Example:
```lua
script.Parent.Transparency = 0.5
```

### `ClipsDescendants: boolean`
Whether the UI instance should clip the children out of it.

---

## Events
### `MouseEnter`
Fired whenever the mouse enters the UI instance. Example:
```lua
script.Parent.MouseEnter:Connect(function()
    print("Mouse entered")
end)
```

### `MouseLeave`
Fired whenever the mouse leaves the UI instance. Example:
```lua
script.Parent.MouseLeave:Connect(function()
    print("Mouse left")
end)
```

### `MouseMoved`
Fired whenever the mouse moves inside the UI instance. Example:
```lua
script.Parent.MouseMoved:Connect(function()
    print("Mouse moved")
end)
```
