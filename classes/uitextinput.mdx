## Properties
### `Text: string`
The current text in the input.

### `PlaceholderText: string`
The text shown when the input is empty.

### `TextSize: number`
The size of the text in pixels.

### `TextColor: Color3`
The color of the text.

### `PlaceholderTextColor: Color3`
The color of the placeholder text.

### `TextStroke: number`
The thickness of the text's outline.

### `TextStrokeColor: Color3`
The color of the text's outline.

### `Editable: boolean`
Whether the user can edit the text.

### `MaxLength: number`
The maximum number of characters allowed in the input.

### `HorizontalAlignment: HorizontalAlignment`
The horizontal alignment of the text. See the [HorizontalAlignment](/enums/horizontalalignment) enum for the available values.

---

## Events
### `Submitted`
Fired when the user submits the input (for example by pressing Enter). Passes the current text. Example:
```lua
script.Parent.Submitted:Connect(function(text: string)
    print("Submitted: " .. text)
end)
```

### `Changed`
Fired whenever the text changes. Passes the new text. Example:
```lua
script.Parent.Changed:Connect(function(text: string)
    print("Changed: " .. text)
end)
```
