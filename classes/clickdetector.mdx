<Note iconType="regular">
  ClickDetector inherits Instance.
</Note>

A ClickDetector lets you detect when a player clicks on or hovers over the object
it is parented to. Place one inside a [Part](/classes/part) or other object and
connect to its events to respond to mouse interaction.

## Properties
### `MaxActivationDistance: number`
The maximum distance, in studs, a player can be from the object to interact with
it. Example:
```lua
script.Parent.MaxActivationDistance = 32
```

### `Active: boolean`
Whether the ClickDetector is currently active. When `false`, it will not fire any
of its events. Example:
```lua
script.Parent.Active = false
```

---

## Events
### `MouseHoverEnter: Event`
<Note iconType="regular">
  Only fires on the client.
</Note>
Fired when a player's mouse begins hovering over the object. Example:
```lua
script.Parent.MouseHoverEnter:Connect(function(player)
    print(player.Name, "started hovering")
end)
```

### `MouseHoverLeave: Event`
<Note iconType="regular">
  Only fires on the client.
</Note>
Fired when a player's mouse stops hovering over the object. Example:
```lua
script.Parent.MouseHoverLeave:Connect(function(player)
    print(player.Name, "stopped hovering")
end)
```

### `MouseClick: Event`
<Note iconType="regular">
  Only fires on the server.
</Note>
Fired when a player clicks the object with the left mouse button. Example:
```lua
script.Parent.MouseClick:Connect(function(player)
    print(player.Name, "clicked")
end)
```

### `RightMouseClick: Event`
<Note iconType="regular">
  Only fires on the server.
</Note>
Fired when a player clicks the object with the right mouse button. Example:
```lua
script.Parent.RightMouseClick:Connect(function(player)
    print(player.Name, "right-clicked")
end)
```
