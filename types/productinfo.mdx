A `ProductInfo` holds information about a purchasable product, returned by
[MarketService:GetProductInfo](/services/marketservice#getproductinfo-productid-number-productinfo).

## Properties
### `Id: number`
The id of the product.

### `Name: string`
The display name of the product.

### `Description: string`
The description of the product.

### `IconAssetId: number`
The id of the icon asset used to display the product.

### `Price: number`
The price of the product.

### `Kind: ProductKind`
The kind of product.

### `IsForSale: boolean`
Whether the product is currently available for purchase.

### `CreatorId: number`
The id of the creator of the product.
