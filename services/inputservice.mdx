<Note iconType="regular">
  InputService inherits Instance.
</Note>

The InputService provides access to the player's input, such as keyboard,
mouse, touch and gamepad events, the current mouse position and helpers for
converting screen positions into world-space rays.

## Properties
### `MousePosition: Vector2`
The current position of the mouse cursor on the screen. Example:
```lua
local mousePos = game:GetService("InputService").MousePosition
print(mousePos.X, mousePos.Y)
```

### `MouseDelta: Vector2`
The change in mouse position since the last frame.

### `TouchEnabled: boolean`
Whether the device supports touch input.

### `IsWindowFocused: boolean`
Whether the game window currently has focus.

---

## Methods
### `ProjectRayOrigin(screenPosition: Vector2): Vector3`
Returns the world-space origin of a ray cast from the given screen position,
starting at the camera. Example:
```lua
local inputService = game:GetService("InputService")
local origin = inputService:ProjectRayOrigin(inputService.MousePosition)
```

### `ProjectRayNormal(screenPosition: Vector2): Vector3`
Returns the world-space direction of a ray cast from the given screen
position. Used together with `ProjectRayOrigin` to raycast from the mouse.
Example:
```lua
local inputService = game:GetService("InputService")
local origin = inputService:ProjectRayOrigin(inputService.MousePosition)
local direction = inputService:ProjectRayNormal(inputService.MousePosition)

local result = workspace:Raycast(origin, direction * 1000)
if result then
    print("Hit", result.Instance.Name)
end
```

### `IsKeyDown(keyCode: KeyCode): boolean`
Returns true if the given [KeyCode](/enums/keycode) is currently held down. Example:
```lua
local inputService = game:GetService("InputService")
if inputService:IsKeyDown(Enum.KeyCode.Space) then
    print("Space is held down")
end
```

### `IsMouseButtonDown(mouseButton: MouseButton): boolean`
Returns true if the given [MouseButton](/enums/mousebutton) is currently held down. Example:
```lua
local inputService = game:GetService("InputService")
if inputService:IsMouseButtonDown(Enum.MouseButton.Left) then
    print("Left mouse button is held down")
end
```

### `GetMouseLocation(): Vector2`
Returns the current position of the mouse cursor on the screen.

### `GetStringForKeyCode(keyCode: KeyCode): string`
Returns the display string for the given [KeyCode](/enums/keycode). Example:
```lua
local inputService = game:GetService("InputService")
print(inputService:GetStringForKeyCode(Enum.KeyCode.Space)) -- "Space"
```

### `GetKeyCodeFromString(key: string): KeyCode`
Returns the [KeyCode](/enums/keycode) matching the given string.

---

## Events
### `WindowFocused: Event`
Fired whenever the game window gains focus.

### `WindowFocusReleased: Event`
Fired whenever the game window loses focus.

<Note iconType="regular">
  The input events below only fire on the client, so connect to them from a
  [LocalScript](/classes/localscript).
</Note>

Each input event passes an [InputObject](/types/inputobject) describing the
input, and a `gameProcessed` boolean. `gameProcessed` is `true` when the input
was already handled by something else, such as typing into a
[UiTextInput](/classes/uitextinput) or clicking a button, so most gameplay code
should ignore those inputs.

### `InputBegan: Event<InputObject, boolean>`
Fired when an input starts, such as a key, mouse button, touch or gamepad
button being pressed. Example:
```lua
local inputService = game:GetService("InputService")

inputService.InputBegan:Connect(function(input: InputObject, gameProcessed: boolean)
    if gameProcessed then return end

    if input.KeyCode == Enum.KeyCode.E or input.KeyCode == Enum.KeyCode.ButtonX then
        print("Interact pressed")
    end
end)
```

### `InputChanged: Event<InputObject, boolean>`
Fired when an ongoing input changes, such as the mouse moving, the wheel
scrolling, a finger dragging, or a thumbstick or trigger moving. Example:
```lua
local inputService = game:GetService("InputService")

inputService.InputChanged:Connect(function(input: InputObject, gameProcessed: boolean)
    if input.InputType == Enum.InputType.MouseWheel then
        print("Scrolled", input.Value.Y)
    elseif input.KeyCode == Enum.KeyCode.Thumbstick1 then
        print("Left stick at", input.Value.X, input.Value.Y)
    end
end)
```

### `InputEnded: Event<InputObject, boolean>`
Fired when an input ends or is cancelled, such as a key, mouse button, touch or
gamepad button being released.
